01

About the Project

Mosswood Apothecary is a browser-based game I created from scratch to challenge myself to build something interactive outside of my coursework. The game is centered around running a woodland apothecary, where players can forage for ingredients, manage resources, and use what they collect throughout the game.

I wanted this project to be something that combined programming with a style and concept I genuinely enjoyed. Building Mosswood gave me the opportunity to work more with JavaScript while also designing the interface and overall experience of the game.

04

Development

THE PROCESS

Building Mosswood

I developed Mosswood using HTML for the structure, CSS for the visual design, and JavaScript for the game's functionality and interactive systems.

As the project grew, I had to think about how the different parts of the game worked together rather than treating each feature separately.

CHALLENGES

Problem Solving

One of the biggest parts of developing the game was keeping track of how different resources and actions affected one another while making sure the interface stayed easy to understand.

Testing the game also helped me find unexpected interactions and bugs that I could go back and correct as I continued developing it.

05

What I Learned

Mosswood gave me more hands-on experience using JavaScript to create an interactive application rather than just a static website. I worked with game logic, changing values, user actions, resource management, and keeping different parts of the interface updated as the player interacts with the game.

It also gave me more experience debugging my own work. As I tested the game, I found things that did not behave the way I expected and had to trace the problem back through my code. Overall, this project helped me become more comfortable taking an idea and turning it into a complete working project.
