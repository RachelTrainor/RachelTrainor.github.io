Weigh To Go

App Overview

Weigh To Go is an Android weight-tracking application that I originally created in CS 360: Mobile Architecture and Programming. The application allows users to track their weight and monitor their progress toward a goal.

I chose Weigh To Go as the main artifact for my CS 499 capstone and enhanced it across software design and engineering, algorithms and data structures, and databases.

Login/Register Screenshot

Login and Registration

The login and registration screen allows users to create an account or sign in to an existing account before accessing their weight information.

Home Screen Screenshot

Home Screen

The home screen gives users a quick view of their current weight and goal weight. From here, users can access the weight log and other features of the application.

Weight Log Screenshot

Weight Log

The weight log allows users to add and manage their weight records. Users can view previous entries, edit existing records, delete records, and organize their weight history.

Weight Progress Screenshot

Weight Progress

The weight progress screen analyzes the user's weight records and provides additional information about their progress. It displays information such as starting weight, current weight, weight change, recent trends, and progress toward the user's goal.

SMS Permissions Screenshot

SMS Permissions

The SMS permissions screen allows the user to manage permission for goal notifications. When permission is available and a phone number has been entered, the application can send an SMS notification when the user reaches their goal weight.
