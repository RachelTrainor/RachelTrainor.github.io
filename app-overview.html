Weigh To Go

App Overview

Weigh To Go is an Android weight-tracking application that I originally created in CS 360: Mobile Architecture and Programming. The application allows users to track their weight and monitor their progress toward a goal.

I chose Weigh To Go as the main artifact for my CS 499 capstone and enhanced it across software design and engineering, algorithms and data structures, and databases.

Application Features

Users can create an account, record and manage weight entries, set a goal weight, track their progress, and receive SMS notifications when they reach their goal.
